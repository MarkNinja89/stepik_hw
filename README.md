# Проект "Разговорный немецкий"  🚩
## Описание
 Всем привет! Тут делюсь моими планами и стратегий изучения немецкого языка, чтобы потом легко на нём говорить и сдать экзамен.

## Цели
1. :white_check_mark: Изучить немецкий до уровня B1  с преподавателем и самостоятельно.
2. :white_check_mark: Поддерживать мощный лексический запас слов
3. :white_check_mark: Освоить свободное говорение на немецком
4. :white_check_mark: Сдать экзамен с международным подтверждением на уровень B1.

## Что необходимо
1. :train: Ежедневно в транспорте слушать аудиоуроки с повторением слов, диалогов и предложений.
2. :pencil: Регулярно 2 раза в неделю заниматься с преподавателем.
3. :green_book: Делать все упражнения из учебников.

## Заключение.
:mortar_board: Экзамен будет сдан!
